# movie-posters
A movie poster application that was built for CS 460, Software Engineering for Mobile Devices, at Central Washington University. It was developed in Android Studio Panda 4 (API level 26) using Java and XML. The original code was provided by Dr. Shangyue Zhu and was meant to be modified to meet specific requirements. The first commit to this repository included the original files; all other commits include modifications and additions.

There are four pages: Home, Watchlist, Random, and Contact Us. 
  - The Home page lists movies for the user to explore. The user may select any number of movies and add them to their watchlist. Listed movies have a title, poster, rating, producer(s), and a short description.
  - The Watchlist page lists all movies the user added from the Home page. Movies can be removed from this list by pressing the heart icon.
  - The Random page displays random stills from movies that are in the movie list on the Home page. Since it is a prototype, the random content is predefined; however, in a commercial environment, this content would be pulled from a database instead of
    burdening local memory.
  - The Contact page provides a short description of the Movie Favs company and a toggle for displaying the information of the code's modifier (me). When the company's information is displayed, the user may select the email card to be redirected to the company's
    email address in their default email app.
